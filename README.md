## ✨ Features

- 🏠 Home screen with music categories and recommendations
- 🔍 Search interface for songs, artists, and albums
- 🎵 Library for liked songs, playlists, downloads, and local audio
- 🎧 Music player with playback controls
- 🎚️ Five-band graphic equalizer interface
- 📊 Listening statistics and top artists
- 🌑 Dark AMOLED-inspired theme
- 💚 Vibrant green accent colors
- 📱 Bottom navigation
- 💾 Backup and restore interface

## 🛠️ Technology Stack

- **Kotlin** — Android development
- **Jetpack Compose** — Native UI toolkit
- **Material 3** — UI components
- **AndroidX Media3 / ExoPlayer** — Audio playback
- **Room Database** — Local data storage

Actual functionality depends on the integrations implemented in the project source code.

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the Android project in Android Studio.
3. Wait for Gradle synchronization.
4. Select an emulator or connect an Android device.
5. Press **Run** to launch the app.
